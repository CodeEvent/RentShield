How to fulfill a "Real Notary Public" request — what RentShield automates, and what you do by hand for the actual notarization. This page is the always-available reference; the guided walkthrough (top right, or replay any time) points at the same steps below. Click the on any step for more detail.

What this role is

When a landlord selects the "Real Notary Public" add-on, RentShield tags their notice Awaiting Notary Public and emails you. There is no UAE notary that exposes an API today, so everything past that email is you — you notarize it the same way you always have, then record the result back onto the notice yourself. RentShield doesn't have a special screen for this: you do it all in paperless-ngx's normal document editor, the same one used for every other document here.

1. Find notices waiting on you

Every notice tagged "Awaiting Notary Public" hasn't been handled yet, oldest first. You can also find this list under Saved Views as "RentShield: Notary Public Queue".

Open the queue
2. Open one and read it

Landlord, tenant, reason, and notice date are already on the notice as fields — no separate form to fill in. Open the notice like any other document to see them.

3. Do the physical notarization

Outside the app, exactly as before this existed — this step is entirely yours.

4. Upload the stamped copy

Drag the scanned/stamped notarized PDF anywhere in this app to upload it as its own new document, the same way any document gets added here.

5. Record it on the original notice

Back on the original notice's edit view, under Custom Fields: link your upload via RentShield: Notarized Copy, and fill in RentShield: Notary Reference No. Set RentShield: Notary Public Status to completed — or rejected with a note in RentShield: Notary Notes if it couldn't be done.

6. Mark it done

Swap the notice's tag: remove Awaiting Notary Public, add Notary Public Completed (or Notary Public Rejected). That's what moves it off your queue.
